# Pulse Design System

라이프스타일 챌린지 앱 UI 레퍼런스(홈 대시보드, 챌린지 선택, 스케줄 캘린더, 타임피커 등)를 분석해서, 재사용 가능한 컴포넌트 단위로 다시 정리한 디자인 시스템 쇼케이스입니다.

## 왜 만들었나

레퍼런스 화면들은 화면마다 따로 그려진 상태라, 같은 버튼/카드/칩이 화면마다 색상·간격이 미묘하게 달랐습니다. 이 프로젝트는:

1. 반복되는 UI 패턴을 찾아 **컴포넌트로 추상화**하고
2. 색상·타이포·간격·반경을 **디자인 토큰(CSS 변수)**으로 뽑아내고
3. 그 컴포넌트들만 다시 조립해서 **원본 화면을 재현**할 수 있는지 검증

하는 과정을 그대로 보여주는 걸 목표로 합니다.

## 포함된 것

- **Foundations**: 색상, 타이포 스케일, 8단계 여백, 5단계 반경
- **Components**: 버튼(4톤), 칩/태그, 세그먼트·언더라인 탭, 통계/프로모션/리스트 카드, 검색 입력, 체크 필, 토글 스위치, 상단 앱바, 하단 탭바, 프로필 칩, 월간 캘린더, 주간 스트립, 일정 카드, 타임피커 바텀시트
- **In Action**: 위 컴포넌트만으로 조립한 실제 화면 2종 (홈 대시보드 / 챌린지 선택)
- 라이트/다크 테마 토글 지원

## 기술 스택

순수 HTML / CSS(커스텀 프로퍼티 기반 토큰 시스템) / Vanilla JS. 프레임워크 없이 마크업·스타일 설계 역량을 그대로 보여주기 위한 선택입니다.

## 로컬 실행

정적 파일이라 별도 빌드가 필요 없습니다. 아무 정적 서버로 `index.html`을 열면 됩니다.

```bash
npx serve .
# 또는
python -m http.server 5500
```

## 폴더 구조

```
css/
  tokens.css      디자인 토큰 (색상/타이포/간격/반경/그림자)
  base.css        리셋 + 레이아웃 유틸리티
  components.css  버튼/카드/칩/폼/내비/캘린더 등 컴포넌트
  layout.css      헤더/히어로/폰 프레임/푸터
js/
  main.js         테마 토글, 탭 전환, 칩 삭제, 체크/스위치 인터랙션
index.html
```
